# 技术八股与掌握度清单 · 模板

> 复制为 `八股与掌握度_<项目名>.md` 后填写。
> 用途：让八股与源码模块一一对应，并明确「目标掌握等级」与「当前等级」。
> 原则：八股用于整理考点，**不作为技术事实的唯一依据**；技术事实回到官方文档/源码/可靠文章核验。

---

## 一、掌握度分级（统一标准）

| 等级 | 名称 | 标准 |
|---|---|---|
| L0 | 识别 | 听过概念，能辨认名词，不能独立说明 |
| L1 | 解释 | 不看答案能说清概念、解决的问题和基本工作方式 |
| L2 | 结合项目 | 能指出本项目真实代码位置，解释输入输出与调用链，并复现/验证 |
| L3 | 权衡与排障 | 能比较替代方案、解释成本与边界、分析失败场景、定位问题并说明兜底 |

**要求：** 简历核心技术与高频追问 ≥ L2；关键选型 / 核心 Agent 机制 / 重点项目链路 ≥ L3；证据不足则标注「当前无法通过该等级验证」。

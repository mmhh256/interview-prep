## 一、等级与独立证据

| 实际等级 | 标准 |
|---|---|
| 未验证 | 没有独立作答/操作证据；看过、听过、照读不算 |
| L0 | 已测但核心定义/机制答不出或明显错误 |
| L1 | 独立解释概念、问题与基本机制，尚不能完成定位与验证 |
| L2 | L1 + 实际源码/调用链定位 + 不同输入的运行或静态验证，解释输出和边界 |
| L3 | L2 + 独立替代取舍、成本边界及故障定位/兜底推理 |

纯知识题可用可读官方资料与最小案例验证，不证明某项目有该能力或本人做过。**目标等级另列**：核心机制至少 L2，关键选型/排障按岗位需要设 L3；目标不是实际表现。验证有效性为未验证 / 有效 / 需复核 / 已失效。

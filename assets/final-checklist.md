## 一、F 事实与 C 职责

- [ ] 全部范围内 Bullet 编号、有综合状态及独立 F/C/M；覆盖全部不等于全部通过。
- [ ] 重点经历核心断言有实际可读源码/原始来源、版本、范围、时间与限制；代码不被用来证明作者、生产指标或真实选型动机。
- [ ] 本人职责经明确确认，保留原话/范围及交叉证据；仅自述如实标 `[本人确认]`，未知/冲突不改成参与/同事/团队。
- [ ] 指标有口径、数据、基线与测量依据；待核数字不作事实型讲述。
- [ ] 来源/实现/贡献变化与反证已按独立失效条件更新有关记录；历史和无关依据保留。

## 二、M 独立表现（实际与目标分开）

- [ ] 能独立沿真实代码解释核心成功路径与异常分支，记录定位及运行输出或不同输入静态过程；不是只读架构图。
- [ ] 核心机制目标至少 L2，对应有效独立证据；关键选型/排障目标 L3 时有替代方案、成本边界和故障推理。
- [ ] 技术九问、业务五问按范围有独立作答、定向补充与复验记录，未知业务事实不编造。
- [ ] 概念、项目/机制、取舍、故障四类有原始表现；参考答案与照读不计升级，未验证如实列出。
- [ ] 重点个人经历满足联合门槛：F 当前有效且已核，C 真实职责明确且来源诚实，M 有效达到目标。机制训练通过不冒充个人实现 Bullet 通过。

## 三、岗位与讲述

- [ ] 能独立按 30 秒/2 分钟/5 分钟结构讲清所选项目并回应三层追问；讲述只含有依据的事实与确认职责。
- [ ] JD 完整性、职级与轮次已说明；核心能力有证据和目标，缺口与补强计划明确，计划不算已获能力。
- [ ] 使用的公司事实/技术来源带原始出处和日期；未查证/假设单独标注，不编造公司部署、营收或客户。
- [ ] JD 变化只调整有关目标/优先级，并重验新增要求，不自动升级或清零原有能力。
